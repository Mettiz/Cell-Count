# CellCount Lab (نسخه اندروید + نسخه وب PWA)

دستیار جامع و هوشمند آزمایشگاه کشت سلول با ۶ ماژول کامل:

1. **رقت و سرم (`C₁V₁ = C₂V₂`)**: محاسبه دوطرفه، تبدیل آنی `mL / L` و `میلیون / عدد کامل`، حالت کل استوک یا برداشت جزئی، پایه سرم از حجم اضافه‌شده یا کل حجم نهایی، و هشدار سانتریفیوژ.
2. **شمارشگر عکس لام نئوبار (آفلاین سبک CountThings + لمسی)**: موتور بینایی ماشین با OpenCV 4.11 در اندروید، انتخاب الگوی لمسی (Tap-to-Template)، تنظیم حساسیت و اندازه نشانه، جدول ۴×۴ خانه‌های نئوبار و خروجی عکس علامت‌گذاری‌شده.
3. **میکس سوسپانسیون‌های سلولی**: ترکیب نامحدود نمونه‌ها و مدیای اضافی با انتقال مستقیم به بخش رقت.
4. **شمارشگر دستی لام نئوبار**: شمارش خانه‌های بزرگ، درصد زنده‌مانی (Viability) و کل سلول زنده.
5. **پیش‌بینی رشد سلول (لجستیک و نمایی)**: پشتیبانی از رده‌های **BHK-21 / BHK BSR-T7/5 / HeLa / HEK293 / CHO / ...** و ظروف کشت از پلیت ۹۶ خانه تا **بیوراکتورهای 100L، 700L، 1500L و 2700L** + محاسبه تجربی Doubling Time.
6. **پلیت‌ریزی، فلاسک و بیوراکتور + تاریخچه**: محاسبه مسترمیکس با درصد خطای پیپتینگ (Overfill).

## دریافت نسخه اندروید (APK) در گیتهاب

ورک‌فلو خودکار `.github/workflows/android-apk.yml` با هر `Push` (یا اجرای دستی از تب **Actions**) فایل نصب اندروید را می‌سازد:
- از بخش **Releases** در سمت راست مخزن گیتهاب، فایل `CellCount-Lab.apk` را دانلود و نصب کنید.
- یا در تب **Actions ← Build Android APK** آخرین اجرا را باز کرده و فایل `CellCount-Lab-APK` را دانلود کنید.

## نسخه وب (GitHub Pages)

ورک‌فلو `.github/workflows/pages.yml` نسخه وب و PWA پروژه (`index.html`) را روی **GitHub Pages** منتشر می‌کند تا از طریق مرورگر گوشی یا دسکتاپ نیز قابل استفاده و نصب باشد.
